# Reference reels — style breakdown
Source: two screen recordings of Instagram reels (46s + 27s), creator account with Arabic voiceover, "Original audio".

## Look
- Pixel-art / 8-bit retro game aesthetic. Dark near-black background (#141414-ish) with a faint dot grid.
- Recurring narrator: a cartoon girl in a pink hijab, anchored bottom-right (small) as host; big and centered in the intro.
- Recurring mascot: an orange pixel robot/monster "assistant" that reacts, talks, holds things.
- Palette: orange/terracotta accent, yellow, teal, purple, red; white pixel text.
- Arabic text in a pixelated/chunky Arabic font, kinetic, word-by-word; Latin text in pixel font.

## Shot vocabulary (what happens every 1–3 s)
1. Dialogue bubbles (speech balloons) between host and mascot — intro gag.
2. "<< REWIND" VHS glitch transition.
3. Big pixel counters ticking up (00:57 timer, 456,104 → 500,000+ مشاهدة).
4. Giant pixel numbers "1", "2" as chapter cards inside a thin frame.
5. Floating UI cards / notifications popping in with ✕ buttons, the mascot pushing them.
6. Checklist card with green ticks appearing one by one; red stamp "مش مضطر!" slammed diagonally.
7. Folder icon with sparkles labeled MOTION-REEL (file drop moment); comment box typing "skill".
8. Fake app UI (Pinterest-like masonry grid) with search typing, then "0 نتائج" result.
9. Retro fighting-game "VS" screen (red/teal split, health bars, "?" block, "ليه لا؟!" bubble).
10. Lightbulb with rays → "فكرة".
11. Brand identity board slides in, labels BRAND IDENTITY + CHARACTER as pixel tags.
12. Polaroid photo of character + mascot, dotted connection line.
13. Character sheet, then 360° turntable on a light grid stage with callout labels popping (ست مصرية / 60 سنة / أسود في أسود ...).
14. Paper SCRIPT document sliding/rotating in.
15. "TTS" big pixel title, blurred colored orbs behind a frosted-glass card, text writes in (Text To Speech), ElevenLabs badge.

## Motion
- Snappy springs, pops with overshoot, hard cuts on the voice beat; pixel stepping, typewriter text.
- Constant new thing every ~1–2 s; never a dead frame.
- Sound: voiceover drives the edit; UI clicks, blips, game SFX.

## Adapting to Kara Duo
Keep the structure/energy (host + mascot, game UI, counters, checklists, VS, turntable with callouts),
swap the palette to the brand (ivory/lavender/mauve/Kara pink), use the Khuzama flower + sparkle star
as the pixel iconography, Cairo/Tajawal for Arabic. Note the guide prefers light/lavender grounds and
forbids black backgrounds → use deep mauve #654A70 as the "dark" stage instead of black.
